# Формика — проект Godot

Этап 1 по плану из `CLAUDE.md`: прототип битвы. Отряды, приказы мышью, урон, запах колонии и бегство. Графика из кубиков.

## Запуск

1. Godot 4.5 или новее. Открыть папку проекта в менеджере проектов (файл `project.godot`).
2. Нажать F5. Главная сцена `battle/battle.tscn`.

## Что проверить в редакторе

- Открывается поле: коричневая земля, три рыжих блока снизу, три чёрных сверху, над каждым номер.
- ЛКМ по своему отряду выделяет его (золотое кольцо). Рамкой можно выделить несколько.
- ПКМ по земле: отряд идёт, несколько отрядов встают рядом. ПКМ по врагу: атака.
- Клавиши: 1 2 3 выбор отряда, L линия, K колонна, H стоять, A все, Space пауза, Esc снять выделение.
- Когда отряды сходятся, у обоих падает численность и «запах колонии» на карточке снизу. Удар с фланга и с тыла сбивает запах сильнее.
- Отряд с запахом ниже 18 бежит (подпись «бегут»), бегущих рубят быстрее, далеко от врага запах восстанавливается и отряд приходит в себя.
- Когда все чёрные разбиты или бегут, появляется экран итога.

## Файлы

| Файл | Что |
| --- | --- |
| `battle/battle.gd` | Поле, камера, свет, симуляция, ввод мышью и клавишами, противник |
| `battle/squad.gd` | Отряд: позиция, строй, муравьи через MultiMesh, мораль, урон |
| `battle/battle_ui.gd` | Интерфейс: цели, время, карточки отрядов, приказы, итог |
| `art/prototype_web/formica-battle.html` | Браузерный прототип той же механики с текстурами, для быстрых проб баланса |

Все константы баланса в начале `battle/battle.gd` и `battle/squad.gd`.

## MCP для Claude Code

`.mcp.json` подключает два локальных сервера. Пути нужно поправить под свой компьютер.

**Godot** — сервер [godot-mcp](https://github.com/Coding-Solo/godot-mcp): запускает проект, читает вывод отладки, создаёт сцены и узлы.

```bash
git clone https://github.com/Coding-Solo/godot-mcp C:/tools/godot-mcp
```

```bash
cd C:/tools/godot-mcp && npm install && npm run build
```

В `.mcp.json` указать путь к `build/index.js` и к `Godot.exe` в `GODOT_PATH`.

**Blender** — сервер [blender-mcp](https://github.com/ahujasid/blender-mcp). Нужен `uv` (Python) и аддон в Blender:

1. Скачать `addon.py` из репозитория, в Blender: Edit → Preferences → Add-ons → Install, включить «Blender MCP».
2. В 3D-виде нажать N, вкладка BlenderMCP → Start MCP Server.
3. Claude Code запустит `uvx blender-mcp` сам по `.mcp.json`.

Python отдельного сервера не требует: Claude Code запускает скрипты напрямую.
